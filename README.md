# Portfolio

Portfolio website built using vanilla JavaScript, Python and FastAPI.

## About

My personal portfolio site, built from scratch without frontend frameworks.
The frontend is plain HTML, CSS and JavaScript. The backend is a small
REST API written in Python with FastAPI, which serves the projects data
and handles the contact form.

## Tech Stack

**Frontend:** HTML, CSS, JavaScript (no framework)
**Backend:** Python, FastAPI
**Database:** SQLite
**Deployment:** GitHub Pages (frontend), Render (backend)
